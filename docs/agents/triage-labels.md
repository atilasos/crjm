# Triage labels

As cinco funções de triagem usam os nomes padrão no GitHub.

| Função da skill | Etiqueta no projeto | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Aguarda avaliação |
| `needs-info` | `needs-info` | Aguarda informação adicional |
| `ready-for-agent` | `ready-for-agent` | Especificação pronta para implementação por um agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será implementado |

Quando uma skill indicar uma destas funções, aplicar a etiqueta correspondente. Preservar as outras etiquetas do projeto. Alterar a coluna "Etiqueta no projeto" se o vocabulário mudar.
